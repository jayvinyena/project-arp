# 사용 가이드

아트 리소스 플래너(ARP)는 런칭과 업데이트에 필요한 아트 물량을 설계하고, 같은 인력으로 언제 끝나는지 계산하는 도구입니다. 서버는 없습니다. 데이터는 **프로젝트 파일(.arp)** 하나에 모두 저장되고, 계산은 사용자 컴퓨터의 브라우저에서 수행합니다.

## 시작하기

| 하려는 것 | 시작 화면에서 |
|---|---|
| 팀에서 쓰던 파일 열기 | **프로젝트 파일 열기** → 공유 드라이브의 `.arp` |
| 처음부터 만들기 | **새 프로젝트 만들기** → 기본 정보 · 파트 · 리소스 · 런칭 4단계 |
| 엑셀 데이터로 만들기 | **엑셀로 가져오기** → **빈 양식 받기**(또는 예시 양식) → 양식을 채운 뒤 **채운 파일 선택**. 양식의 첫 시트 "안내"에 칸마다 형식과 설명이 있습니다 |
| 옛 구글 시트 도구에서 옮기기 | 구글 시트에서 **파일 → 다운로드 → Microsoft Excel** → **엑셀로 가져오기** → **채운 파일 선택**(양식 없이 그대로) |
| 둘러보기 | **예시 프로젝트로 둘러보기** |

- 크롬 또는 엣지를 사용합니다. 수정한 내용은 2초 뒤 연 파일에 자동 저장됩니다. 즉시 저장하려면 Ctrl+S를 누릅니다.
- 처음 열 때 **내 이름**을 입력합니다. 변경 이력과 "편집 중" 표시에 기록됩니다.
- 주소창 오른쪽의 **설치** 버튼을 누르면 앱처럼 사용할 수 있으며, 인터넷 연결 없이도 열립니다.

## 화면

| 메뉴 | 하는 일 |
|---|---|
| 런칭 물량 설계 | 물량 템플릿 3개(기본 이름 최소안·기본안·최대안, 이름은 물량 표 제목에서 바꿀 수 있음)를 카드나 물량 표의 열 머리글로 선택해, 강조된 열(편집 중)에 수량을 입력하고 템플릿별 완료 예정·파트 부하를 확인합니다. 물량 표는 세 템플릿을 열로 나란히 보여 줍니다. "최소안 → 기본안 복사"처럼 방향이 적힌 버튼으로 빠르게 채웁니다. "거꾸로 계산하기"는 최대 물량과 필요 인원을 자동으로 계산합니다 |
| 업데이트 계획 | 런칭과 업데이트를 한 타임라인에 배치합니다. 업데이트 만들기(유형 템플릿 복사), 우선순위 바꾸기, 날짜·물량 고치기 |
| 작업 진척 | 파트별로 끝낸 개수를 입력합니다. 남은 작업만 다시 계산해 완료 예정이 즉시 변경됩니다 |
| 시뮬레이션 | 원본을 바꾸지 않는 "시나리오"를 만들어 인원·외주·AI 비율·물량·날짜 등을 변경해 원본과 나란히 비교합니다. 채택한 시나리오만 원본에 반영합니다 |
| 마감 맞추기 | 모든 업데이트가 마감을 지키려면 인원·외주·물량·우선순위를 어떻게 변경해야 하는지 제안합니다. 허용할 수단만 켜고, 채택하면 **시나리오로 만들기** → 시뮬레이션에서 비교 → 원본에 반영 |
| 프로젝트·파트·리소스 | 새 프로젝트를 만들 때 입력한 정보(이름·여유율·근무 요일·휴일, 파트와 기본 인원·가동률·AI 활용 비율, 리소스와 파트별 기본·AI 공수)를 수정합니다 |
| 유형 템플릿 | 업데이트 유형(시즌, 미니 …)별 기본 물량을 관리합니다 |
| 인력 | 파트 × 달 인원·가동률·외주·지원. 계획 기간도 여기서 조정합니다 |
| 공수 보정 | 작업 진척의 실투입 인·일로 실제 공수를 구해 기준 공수 보정을 제안합니다 |
| 변경 이력 | 누가 언제 무엇을 바꿨는지. 잘못 고쳤으면 **되돌리기** |
| 데이터 점검 | 계산을 막는 오류와 주의. 오류가 있으면 계산하지 않고 원인을 표시합니다 |

왼쪽 아래 **보고용 엑셀 내보내기**는 보고용 엑셀을 만듭니다. **편집용 엑셀 내보내기**는 가져오기 양식 형식으로 내보내며, 엑셀에서 대량으로 수정한 뒤 시작 화면 **엑셀로 가져오기**로 다시 가져오면 새 프로젝트 파일이 됩니다. 업데이트 전망, 파트 부하, 물량, 인력, 작업 진척, 변경 이력이 포함됩니다.

화면마다 제목 위 **이 화면 안내** 버튼(또는 키보드 **?**)을 누르면 해당 화면의 용도, 사용 순서, 용어, 관련 화면이 오른쪽에 표시됩니다.

## 판정 읽는 법

| 판정 | 뜻 |
|---|---|
| 목표 안 | 아트 작업이 제작 완료 목표일 안에 끝납니다 |
| 빠듯 | 제작 완료 목표일은 넘지만 출시일 안에 끝납니다 |
| 늦음 | 출시일을 넘깁니다(+영업일) |
| 기간 안에 못 끝남 | 계획 기간이 끝날 때까지 끝나지 않습니다. 인력 또는 계획 기간을 늘립니다 |

**근거**는 가장 늦게 끝나는(또는 못 끝내는) 파트·리소스입니다. 해당 파트의 인원을 늘리거나 해당 리소스의 물량을 줄이는 것을 먼저 검토합니다.

## 여럿이 쓸 때

- 파일 하나는 한 번에 한 사람만 수정합니다. 다른 사람이 열어 둔 파일은 **"○○님이 편집 중"**이 표시되고 읽기 전용으로 열립니다. 상대가 닫거나 30분 동안 저장이 없으면 수정할 수 있습니다.
- 연 뒤 다른 곳에서 파일이 변경되면 덮어쓰지 않고 **충돌**을 표시합니다. 다른 이름으로 저장하거나 다시 엽니다.
- 작업을 마치면 **닫기**를 누릅니다. "편집 중" 표시가 즉시 해제됩니다.

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 저장하지 않고 창을 닫음 | 다시 열면 시작 화면에 **되살리기**가 표시됩니다 |
| 잘못 수정함 | **변경 이력 → 되돌리기** |
| "계산할 수 없습니다" | **데이터 점검**에서 수정할 곳과 방법을 확인합니다 |
| 옛 구조 파일이라는 알림 | 새 구조로 열린 상태입니다. 옛 앱에서도 열어야 하면 **원본 받기**를 누릅니다 |
| 화면이 "문제가 생겼습니다"로 바뀜 | 새로 고침합니다. 저장하지 않은 작업은 되살리기로 복구됩니다 |
