# 사용 가이드

아트 리소스 플래너(ARP)는 런칭과 업데이트에 필요한 아트 물량을 설계하고, 같은 인력으로 언제 끝나는지 계산하는 도구예요. 서버가 없어요. 데이터는 **프로젝트 파일(.arp)** 하나에 모두 들어 있고, 계산은 내 컴퓨터의 브라우저에서 해요.

## 시작하기

| 하려는 것 | 시작 화면에서 |
|---|---|
| 팀에서 쓰던 파일 열기 | **프로젝트 파일 열기** → 공유 드라이브의 `.arp` |
| 처음부터 만들기 | **새 프로젝트 만들기** → 기본 정보 · 파트 · 리소스 · 런칭 4단계 |
| 옛 구글 시트 도구에서 옮기기 | 구글 시트에서 **파일 → 다운로드 → Microsoft Excel** → **기존 시트(.xlsx) 가져오기** |
| 둘러보기 | **예시 프로젝트로 둘러보기** |

- 크롬이나 엣지를 쓰세요. 고친 내용이 연 파일에 2초 뒤 자동 저장돼요. 바로 저장하려면 Ctrl+S를 누르세요.
- 처음 열 때 **내 이름**을 넣어 주세요. 변경 이력과 "편집 중" 표시에 남아요.
- 주소창 오른쪽의 **설치** 버튼을 누르면 앱처럼 쓸 수 있고, 인터넷이 없어도 열려요.

## 화면

| 메뉴 | 하는 일 |
|---|---|
| 런칭 물량 설계 | 물량 템플릿 3개(기본 이름 최소안·기본안·최대안, 이름은 물량 표 제목에서 바꿀 수 있음)를 카드로 골라 수량을 넣고, 템플릿별 완료 예정·파트 부하를 봐요. "다른 템플릿에도 똑같이"·"○○ 수량 가져오기"로 빠르게 채워요. "거꾸로 계산하기"는 최대 물량과 필요 인원을 자동으로 구해요 |
| 업데이트 계획 | 런칭과 업데이트를 한 타임라인에 놓아요. 업데이트 만들기(유형 템플릿 복사), 우선순위 바꾸기, 날짜·물량 고치기 |
| 작업 진척 | 파트별로 끝낸 개수를 넣어요. 남은 일만 다시 계산해서 완료 예정이 바로 바뀌어요 |
| 시뮬레이션 | 원본을 바꾸지 않는 "시나리오"를 만들어 인원·외주·AI 비율·물량·날짜 등을 바꿔 보고, 원본과 나란히 비교해요. 마음에 들면 원본에 반영해요 |
| 마감 맞추기 | 모든 업데이트가 마감을 지키려면 인원·외주·물량·우선순위를 어떻게 바꿔야 하는지 제안받아요. 바꿔도 되는 수단만 켜고, 마음에 들면 **시나리오로 만들기** → 시뮬레이션에서 비교 → 원본에 반영 |
| 프로젝트·파트·리소스 | 새 프로젝트를 만들 때 넣은 것(이름·여유율·근무 요일·휴일, 파트와 기본 인원·가동률·AI 활용 비율, 리소스와 파트별 기본·AI 공수)을 고쳐요 |
| 유형 템플릿 | 업데이트 유형(시즌, 미니 …)별 기본 물량 |
| 인력 | 파트 × 달 인원·가동률·외주·지원. 계획 기간도 여기서 늘려요 |
| 공수 보정 | 작업 진척의 실투입 인·일로 실제 공수를 구해 기준 공수 보정을 제안해요 |
| 변경 이력 | 누가 언제 무엇을 바꿨는지. 잘못 고쳤으면 **되돌리기** |
| 데이터 점검 | 계산을 막는 오류와 주의. 오류가 있으면 계산하지 않고 이유를 보여줘요 |

왼쪽 아래 **엑셀로 내보내기**는 보고용 엑셀을 만들어요. 업데이트 전망, 파트 부하, 물량, 인력, 작업 진척, 변경 이력이 들어가요.

화면마다 제목 위 **이 화면 안내** 버튼(또는 키보드 **?**)을 누르면 그 화면에서 하는 일, 쓰는 순서, 용어, 함께 쓰는 화면이 오른쪽에 나와요.

## 판정 읽는 법

| 판정 | 뜻 |
|---|---|
| 목표 안 | 아트 작업이 제작 완료 목표일 안에 끝나요 |
| 빠듯해요 | 제작 완료 목표일은 넘지만 출시일 안이에요 |
| 늦어요 | 출시일을 넘어요(+영업일) |
| 기간 안에 못 끝나요 | 계획 기간이 끝날 때까지도 못 끝나요. 인력이나 기간을 늘려 보세요 |

**근거**는 가장 늦게 끝나는(또는 못 끝내는) 파트·리소스예요. 그 파트의 인원을 늘리거나 그 리소스의 물량을 줄이는 것이 먼저예요.

## 여럿이 쓸 때

- 파일 하나는 한 번에 한 사람만 고쳐요. 누가 열어 두었으면 **"○○님이 편집 중"**이 뜨고 읽기 전용으로 열려요. 상대가 닫거나 30분 동안 저장이 없으면 고칠 수 있어요.
- 내가 연 뒤 다른 곳에서 파일이 바뀌었으면 덮어쓰지 않고 **충돌**을 알려요. 다른 이름으로 저장하거나 다시 열어 주세요.
- 다 쓰면 **닫기**를 눌러 주세요. "편집 중" 표시가 바로 풀려요.

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 저장하지 않고 창을 닫았어요 | 다시 열면 시작 화면에 **되살리기**가 떠요 |
| 잘못 고쳤어요 | **변경 이력 → 되돌리기** |
| "계산할 수 없어요" | **데이터 점검**에서 고칠 곳과 방법을 보세요 |
| 옛 구조 파일이라는 알림 | 새 구조로 열었어요. 옛 앱에서도 열어야 하면 **원본 받기**를 누르세요 |
| 화면이 "문제가 생겼어요"로 바뀌었어요 | 새로 고치세요. 저장하지 않은 작업은 되살리기로 돌아와요 |
