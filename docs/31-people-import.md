# 작업자를 Jira · 시트에서 가져오기 검토

2026-11-10 · 상태: **적용함**(6절 추천안대로) — 결과는 7절.

요청: "작업자를 Jira나 다른 파일(구글 시트, 엑셀 등)에서 추출하는 부분이 효율이 있을지 검토."

## 1. 지금

| 곳 | 하는 일 |
|---|---|
| 작업자 명단(인력 › 작업자, [24-people.md](24-people.md)) | 손으로 넣는다. 한 줄에 이름 · 소속팀 · 이메일 · 특이사항 + Enter. 소속팀은 목록(파트 + 지원 팀)에서만 고른다 |
| 에셋 담당(`asset_parts.assignee`) | 글자. 담당 칸에서 참여 중인 작업자를 제안하지만 명단과 묶여 있지 않다(명단에 없는 이름도 들어간다) |
| 제작 리스트 가져오기([20](20-asset-management.md) 19절) | 시트의 "원화 담당" 같은 칸을 읽어 에셋 담당 이름으로 넣는다. **명단에는 넣지 않는다** |
| 계산 | 작업자 명단을 쓰지 않는다(인원은 인력 표 숫자) |

## 2. 효율을 따져 보면

명단은 작고 자주 바뀌지 않는다(팀 10 ~ 40명, 들고 나는 사람은 한 달에 몇 명).

| 일 | 손으로 | 가져오기 |
|---|---|---|
| 처음 명단 만들기(40명) | 한 줄 20초 × 40 ≈ **13분, 한 번** | 1 ~ 2분 |
| 들고 나기(한 달 몇 명) | 몇 초 | 파일을 다시 받아 넣는 쪽이 더 느리다 |
| **이름 맞추기**(담당 칸 "김철수" vs 명단 "김철수(원화)") | 눈으로 찾아야 한다 · 빠지기 쉽다 | 담당 칸 이름을 그대로 명단으로 → 처음부터 같다 |

→ 처음 입력을 아끼는 효과는 작다(한 번에 10분 남짓). 실제 이득은 **에셋 담당 이름과 명단을 맞추는 것**이다. 이름이 맞아야 나중에 담당별 에셋 수 · 진행(docs/24 "다음에 넓힐 것")을 셀 수 있다.

## 3. 가져올 곳별

| 가져올 곳 | 방법 | 얻는 것 | 막히는 점 | 판단 |
|---|---|---|---|---|
| **이미 들어온 에셋 담당**(제작 리스트 · 손 입력) | 파일 안의 담당 이름 중 명단에 없는 이름을 모아 보여 준다 | 이름 · 어느 파트에서 일했는지(→ 소속팀 제안) · 에셋 수 | 담당 칸이 비어 있으면 얻을 것이 없다. 이메일은 없다 | **효율 가장 큼** — 입력 0, 이름이 처음부터 맞다 |
| 엑셀 · 구글 시트 명단 | **표를 복사해 붙여넣기**(탭으로 나뉜 글자) | 이름 · 팀 · 이메일 · 메모 | 열 이름이 시트마다 다르다(머리글로 맞추기) · 팀 이름이 목록에 없을 수 있다 | 효율 중간 — 구글 시트 · 엑셀 · Jira CSV를 연 엑셀 모두 같은 길 |
| 엑셀 파일 받기 · 넣기(.xlsx) | 다른 엑셀 넣기처럼 | 붙여넣기와 같음 + 백업 · 왕복 | 붙여넣기보다 손이 한 번 더 간다 | 낮음 — 붙여넣기로 충분 |
| 구글 시트 직접 연결 | Google API(OAuth) 또는 "웹에 게시" 링크 | 자동 갱신 | OAuth는 앱 등록 · 서버가 필요하고(유지비 0 원칙과 어긋남), "웹에 게시"는 명단을 **누구나 볼 수 있게** 공개한다 | **하지 않음** — 시트에서 복사해 붙여넣기 |
| Jira 직접 연결(REST API) | 브라우저에서 API 토큰으로 부르기 | 담당자 · 자동 갱신 | Jira Cloud는 API 토큰 요청에 CORS를 허용하지 않아 브라우저에서 바로 부를 수 없다 — [커뮤니티 답변](https://community.developer.atlassian.com/t/jira-cloud-token-based-auth-cors-isues/37426). OAuth 2.0(3LO)은 앱 등록 · 비밀 값 교환 서버가 필요하다. 토큰을 파일 · 브라우저에 두는 보안 부담 | **하지 않음** |
| Jira 이슈 CSV 내보내기 | 필터 → CSV → 엑셀로 열어 복사 · 붙여넣기 | 담당자 표시 이름 | 개인 정보 정책 때문에 이메일이 들어가지 않는다(일부 열은 계정 ID) — [JRACLOUD-72001](https://jira.atlassian.com/browse/JRACLOUD-72001), [Atlassian KB](https://support.atlassian.com/jira/kb/how-to-export-the-reporters-email-for-the-issues-returned-in-a-jql/). 팀 정보 없음. 제작 리스트에 담당이 이미 있으면 겹친다 | 붙여넣기로 받는다(따로 만들지 않음) |
| Atlassian 관리자 사용자 내보내기 | admin.atlassian.com › 디렉터리 › 사용자 내보내기(CSV) — [Export users from a site](https://support.atlassian.com/security-and-access-policies/docs/export-users-from-a-site/) | 이름 · 이메일 · 상태 | 조직 관리자만 할 수 있고, 조직 전체(아트 팀 밖 수백 명)가 나온다 | 붙여넣기로 받을 수 있지만 걸러 내는 수고가 크다 |

## 4. 제안

### A. 에셋 담당에서 작업자 찾기 (추천, 먼저)

- 작업자 탭에 **"담당에서 찾기"**. 이 파일의 에셋 담당 이름 중 명단에 없는 것을 보여 준다.
- 줄마다 이름 · **소속팀 제안**(가장 많이 맡은 파트) · 맡은 에셋 수 · 고르기 체크. 소속팀은 고르기 칸(파트 + 지원 팀)으로 바꿀 수 있다.
- "선택한 n명 더하기" → 한 묶음으로 명단에 더한다(되돌리기 한 번).
- 제작 리스트 가져오기 결과 끝에도 "명단에 없는 담당 n명 → 작업자에 더하기" 연결.
- 같은 이름 판정: 앞뒤 공백 · 연속 공백 무시(대소문자 무시). 이미 명단에 있으면 보이지 않는다.
- 크기: 반나절.

### B. 표 붙여넣기 (추천, 같이)

- 작업자 탭 "붙여넣기": 엑셀 · 구글 시트 · Jira CSV(엑셀로 연 것)에서 표를 복사해 넣는다.
- 첫 줄이 머리글이면 열을 맞춘다(이름/Name/담당자, 팀/소속/Team, 이메일/Email, 메모/특이사항/Note). 아니면 이름 · 팀 · 이메일 · 메모 순서.
- 미리보기: **새로 더함** · **이미 있음**(이메일이 비어 있으면 채우기만) · **고칠 것**(이메일 꼴이 틀림, 팀이 목록에 없음).
- 목록에 없는 팀: 줄마다 "지원 팀으로 만들기" 또는 "소속팀 없음"을 고른다(기본 소속팀 없음 — 파트는 만들지 않는다, docs/24).
- 붙여넣은 글은 파일 안에서만 쓰고 어디로도 보내지 않는다.
- 크기: 반나절 ~ 하루.

### C. 엑셀 받기 · 넣기 — 나중에

B로 받을 수 없는 경우(수백 명 · 정기 교체)가 생기면. 지금 엑셀 넣기 틀(import-spec)에 "작업자" 시트를 더하는 방식.

### D. Jira · 구글 시트 직접 연결 — 하지 않음

브라우저만으로는 안 되고(CORS · OAuth) 서버가 필요해 유지비 0 · 로컬 우선 원칙([README](../README.md) "비용: 유지비 0. 서버·DB·로그인 없음")과 어긋난다. 명단은 자주 바뀌지 않아 자동 갱신의 이득도 작다.

## 5. 함께 생각할 것

- **담당 이름 바꾸기 따라가기**: 명단에서 이름을 고치면 그 이름의 에셋 담당도 함께 바꿀지(지금은 따로). A를 만들면 이름이 맞기 시작하므로 같이 하면 좋다(묻고 바꾸기).
- 개인 정보: 이메일은 .arp 파일 안에만. 붙여넣기 · 찾기 모두 서버로 보내지 않는다(docs/24와 같음).

## 6. 정할 것

| 정할 것 | 추천 | 다른 안 |
|---|---|---|
| 1. 에셋 담당에서 찾기(A) | **만든다** | 하지 않음 |
| 2. 표 붙여넣기(B) | **만든다** | 나중에 |
| 3. 엑셀 받기 · 넣기(C) | 나중에 | 지금 |
| 4. Jira · 구글 시트 직접 연결(D) | **하지 않음** | — |
| 5. 목록에 없는 팀 | **줄마다 고르기, 기본 "소속팀 없음"** | 지원 팀으로 자동 만들기 |
| 6. 명단 이름을 고치면 담당 이름도 | **묻고 함께 바꾸기** | 따로 두기(지금) |

## 7. 적용 결과 (2026-11-10)

|---|---|
