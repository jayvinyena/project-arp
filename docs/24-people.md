# 작업자 명단 (2026-11-10)

요청: "실제 작업자를 입력할 수 있는 부분(이름 · 소속팀 · 이메일 · 간단한 특이사항), 인력 페이지에 너무 복잡하지 않게. 바로 페이지에 노출되지 않아도 괜찮음."

## 정한 것

| 항목 | 결정 |
|---|---|
| 위치 | **인력 화면의 "작업자" 탭**. 처음 열면 지금처럼 "파트 × 달 인력" 탭이 보이고, 작업자는 탭을 눌러야 보인다 |
| 칸 | 이름(필수) · 소속팀 · 이메일 · 특이사항 · 참여 |
| 소속팀 | 글자로 적는다. 파트 이름(원화 · 모델링 …)을 제안하고, 파트 이름과 같은 팀은 공정 순서로 정렬 |
| 계산 | **쓰지 않는다.** 완료 예정 계산의 인원은 "파트 × 달 인력" 탭의 숫자 그대로 |
| 쓰는 곳 | 에셋 담당 칸(리스트 · 카드 창)에서 이름을 고를 때 참여 중인 작업자를 제안(직접 적어도 된다) |
| 참여 끄기 | 그만두거나 빠진 사람: 명단에 흐리게 남고 담당 제안에서 빠진다 |
| 이력 | 더하기 · 고치기 · 지우기 모두 변경 이력에 남고 되돌릴 수 있다 |
| 개인 정보 | 이메일 등은 그 프로젝트 파일(.arp) 안에만 저장된다(서버로 보내지 않음). 예시 파일은 가상의 이름 · example.com 주소만 쓴다 |
