# 제작 단계 분포 다시 짜기 (검토)

2026-11-11 · 상태: **추천안(A)대로 고침** — 결과는 6절

요청: "제작 현황판의 제작 단계 분포는 개선이 필요함. 캐릭터 수량 표기를 저렇게 넓게 할당할 필요가 없어 보이고, 이쪽에 추가로 보여줄 정보가 없는지 확인하고 재구성 · 재디자인 검토."

## 1. 지금

- 범례(대기 · 원화 · 모델링 · … · 완료 + 수) 아래 **항목(분류)마다 가로 막대 하나**. 막대는 늘 카드 폭 전부 = 그 항목의 100%.
- "항목별 / 파이프라인별" 전환, "보드에서 보기" 단추.

문제:

1. **막대 축이 항목마다 따로**: 에셋 1개인 항목도 100개인 항목과 같은 길이. "캐릭터 1"이 화면 폭 전부를 차지하고, 항목끼리 크기를 비교할 수 없다.
2. **수만 있고 상태가 없다**: 모델링 단계 5개 중 검수 요청 · 수정 · 보류가 몇 개인지(어디서 막히나) 보이지 않는다. 같은 정보가 "처리할 것" 카드에 흩어져 있다.
3. **오래 머문 것이 안 보인다**: 14일 넘게 같은 파트에 있는 에셋(현황판이 이미 셈)이 단계 위에 표시되지 않는다.
4. **다음 할 일이 없다**: 단계를 눌러 그 에셋으로 갈 수 없다("보드에서 보기"는 전체 보드).
5. 8% 미만 칸은 숫자가 안 보인다(막대 안 글자).

## 2. 더 보여줄 수 있는 정보(이미 있는 자료)

| 정보 | 출처 | 쓸모 |
|---|---|---|
| 단계마다 세부 상태(진행 · 검수 요청 · 수정 · 보류) | 에셋 파트 상태(현황판이 이미 읽음) | **병목**: 어느 단계에 검수 · 수정이 쌓였나 |
| 단계마다 오래 머문 수(14일+) | 처리할 것 "오래 머문 진행"과 같은 기준 | 멈춘 일 |
| 단계마다 이번 주 들어온 · 나간 수 | 파트 시작일 · 완료일 | 흐름이 도는지(들어오기만 하고 안 나가면 병목) |
| 단계마다 담당 수 | 파트 담당 | 한 사람에게 몰렸나 |
| 항목마다 등록 에셋 / 계획 물량 | 물량 대조와 같은 계산 | 아직 등록 안 된 물량 |

## 3. 제안

### A. 단계 흐름 띠 + 항목 표 (추천)

```
 제작 단계 흐름                                   [항목별 | 파이프라인별]  보드에서 보기
 ┌──────┬────────┬────────┬──────────┬──────┬──────┐
 │ 대기 │ 원화   │ 모델링 │ 애니메이션│ FX   │ 완료 │  ← 단계 칸(누르면 그 단계 에셋 리스트로)
 │  12  │   5    │   2    │    1     │  0   │   0  │  ← 큰 수
 │      │진행 3  │수정 1  │진행 1    │      │      │  ← 세부 상태(있는 것만, 색 + 기호)
 │      │검수 1  │진행 1  │          │      │      │
 │      │보류 1  │        │          │      │      │
 │      │⏱ 2    │        │          │      │      │  ← 14일+ 머문 수(있을 때만)
 │      │+3 −1  │ +1     │          │      │      │  ← 이번 주 들어옴 · 나감
 └──────┴────────┴────────┴──────────┴──────┴──────┘
 ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁  ← 전체 20개 한 줄 비율 막대(완료가 오른쪽)

 항목         대기  원화  모델링  애니  FX  완료   등록 / 계획
 캐릭터 20      12    5     2      1    ·    ·    20 / 25
 배경 4          ·    1     ·      ·    ·    ·     4 / 4
```

- **단계 칸**(위): 단계 이름 · 큰 수 · 세부 상태 칩(진행 · 검수 요청 · 수정 · 보류, 0이면 안 보임) · 14일+ 머문 수 · 이번 주 들어옴/나감. 칸을 누르면 에셋 제작 현황이 그 단계로 걸러져 열린다(현황판 → 에셋 거르기와 같은 길).
- **전체 비율 막대 한 줄**: 모든 에셋 기준 하나의 축.
- **항목 표**(아래): 막대 대신 작은 수 표(칸 진하기 = 그 단계 비중), 오른쪽 끝 "등록 / 계획". 1개 항목이 폭을 차지하지 않는다.
- **파이프라인별**: 파이프라인마다 단계 칸 줄(파이프라인 단계 순서, 병렬은 한 칸) — 지금 파이프라인별 보기를 같은 모양으로.
- 카드 폭: 지금처럼 배치 카드와 나란히(넓을 땐) · 좁으면 한 줄 전체. 390은 단계 칸이 가로로 밀린다.

### B. 막대 축만 고치기

막대 길이를 가장 큰 항목 기준으로(1개 항목은 짧게), 막대 안 숫자 대신 막대 끝에 수.

- 문제 1 · 5만 풀린다. 병목 · 머문 것 · 다음 할 일은 그대로 없다.

### C. 누적 흐름 그래프(CFD)

날짜별로 단계마다 쌓인 에셋 수를 띠 그래프로(파트 시작일 · 완료일로 거꾸로 셈).

- 흐름이 막힌 기간이 보이는 가장 강한 그림이지만, 오늘 상태(지금 무엇을 처리할지)는 오히려 덜 보인다. 추이 카드와 겹친다. A 다음 단계로 미룬다.

## 6. 결과

- 카드 이름 "제작 단계 흐름". **단계 칸**(대기 · 파트 · 완료)마다 큰 수 · 세부 상태 칩(진행 · 검수 요청 · 수정 · 보류 · 시작 전, 0이면 안 보임) · 14일+ 머문 수 · 이번 주 들어옴(+) / 나감(−). 단계 이름을 누르면 그 단계, 칩을 누르면 그 단계 · 상태로 걸러진 에셋 리스트가 열린다(에셋 화면에 "단계 …" 거르기 칩, 거르기 풀기로 풂).
- 그 아래 **전체 비율 막대 한 줄**(모든 에셋 한 축).
- **항목 표**: 항목마다 단계별 수(칸 진하기 = 그 항목 안 비중), 오른쪽 "등록 / 계획"(고른 물량 템플릿에 드는 에셋 / 계획 물량, 모자라면 주황). 1개짜리 항목이 폭을 차지하지 않는다.
- **파이프라인별**: 파이프라인마다 같은 단계 칸 줄(병렬 묶음은 한 칸, 누르면 그 파이프라인 · 묶음 파트로 거름).
