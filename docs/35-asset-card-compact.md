# 에셋 카드 패널 줄이기 (검토)

2026-11-11 · 상태: **추천안(A, P1 ~ P6)대로 고침** — 결과는 5절

요청: "보드 뷰의 세부 내역 입력할 때 상단의 박스들이 불필요하게 크게 적용되어 있음. 이 부분을 개선해서 스크롤을 줄이는 것도 괜찮음. 검토 진행."

## 1. 지금 (실측, 예시 에셋 · 패널 720px)

`tools/ux-capture.mjs`와 같은 크롬으로 각 구역 높이를 쟀다(CSS px, 화면 배율 1).

| **속성 상자** | **390** | **390** | 8칸 한 줄씩(단계 · 세부 상태 · 배치 · 마감일 · 포함 템플릿 · Jira 키 · 세부 분류 · 에셋 코드) + 지우기 단추 |

문제:

1. **가장 자주 하는 일(파트 상태 바꾸기)이 첫 화면 아래**. 체크리스트 표 머리가 y ≈ 610에서 시작해 4줄 중 2줄 남짓만 보인다.
2. 속성 상자가 8칸을 **한 칸 한 줄**(라벨 96px + 입력 전체 폭)로 쌓아 390px. 720px 패널에서 입력 칸이 600px까지 늘어나는데, 값은 "원화" · "미배정"처럼 짧다.
3. 자주 바꾸는 4칸(단계 · 세부 상태 · 배치 · 마감일)과 거의 안 바꾸는 4칸(포함 템플릿 · Jira 키 · 세부 분류 · 에셋 코드)이 같은 무게.
4. 라벨 줄이 속성 상자와 같은 값을 한 번 더 보여 준다.
5. 속성 · 링크는 비어 있어도 입력 줄 2칸이 늘 펼쳐져 있다.
6. 390 체크리스트 줄 카드가 파트마다 169px(Jira 입력까지 늘 보임).

## 2. 제안

| # | 바꿀 것 | 1440 | 390 |
|---|---|---|---|
| P1 | **속성 상자를 두 열 격자로**: 자주 쓰는 4칸만 2 × 2(단계 · 세부 상태 / 배치 · 마감일), 칸 높이 32 | 390 → 약 96 | 390 → 약 96(두 열 유지, 칸 폭 약 160) |
| P2 | **나머지 4칸은 "더 보기" 한 줄로 접기**: 접혀 있을 때도 값 요약을 보인다("기본안 · Jira ART-101 · 코스튬 · CK_001"), 누르면 같은 2 × 2 격자로 펼침. 펼침 상태는 브라우저에 기억 | +28(접힘) | +28 |
| P3 | **라벨 줄 없앰**: 같은 값은 상자에 있다. 꼭 눈에 띄어야 하는 것만 이름 아래 설명 줄 끝에 붙인다(마감 지남 빨강, Jira 링크 ↗) | −30 | −58 |
| P4 | **"이 에셋 지우기"는 패널 맨 아래**(댓글 아래, 위험 구역)로. 확인 방식은 그대로 | −40 | −40 |
| P5 | **체크리스트 줄 촘촘히**: 고르기 · 입력 높이 30, Jira 칸은 테두리 없는 칸(올리면 테두리) — 표 밀도 "촘촘"과 같은 규칙 | 줄 45 → 38(−28) | 줄 카드 169 → 약 92: 1줄 = 파트 · 상태, 2줄 = 담당 · 완료일, Jira는 값이 있을 때만(−308) |
| P6 | **속성 · 링크 입력 줄은 "+ 더하기" 단추 뒤로**: 비어 있으면 "아직 없습니다 · + 속성 더하기" 한 줄, 누르면 입력 줄이 열림 | −80 | −120 |

| | 지금 | 제안 후 |

| 1440 전체 높이 | 1,416 | 약 1,000(스크롤 572 → 약 160) |

화면 들썩임 없음: "더 보기"는 누를 때만 펼치고(누른 사람이 원한 움직임), 접힘 줄 높이는 고정. 다른 구역은 자리가 바뀌지 않는다.

## 3. 다른 안

| A. 추천(P1 ~ P6) | 자주 쓰는 4칸 격자 + 나머지 접기 + 중복 · 빈 입력 줄 정리 | 스크롤 약 70% 줄고 체크리스트가 첫 화면. 고치는 곳은 카드 패널 한 곳 |
